# 报修单后续改进

本文记录 2026-07-22 对标填写保修单流程后，未纳入本轮 P1/P3 的改进项。

## P2

- 智能语音录入：支持长按说话，将语音转成故障描述或地址文本；实施前需确定语音识别服务、录音权限、隐私授权和失败回退方案。
- 物流公司搜索：在现有固定物流列表上增加关键词过滤；保留常用物流优先展示和“其他”入口。

## P3

- 提交结果二维码：仅在存在明确的跨设备查看场景时实施。二维码应使用短期、可撤销的访问令牌，不直接包含工单详情或永久可访问链接。

## 验收关注点

- 语音识别失败不应覆盖用户已填写的内容。
- 物流搜索结果必须使用与快递服务商适配层一致的标准名称。
- 二维码访问必须校验工单归属、有效期和访问次数，并避免泄露手机号、地址等个人信息。
