# 微信支付 + 对公转账人工开票配置

> 当前业务规则：**微信支付不进入发票流程；仅已完成结单且已核销的对公转账订单可申请发票，由财务在电子税务局人工开具，再到后台登记发票结果。**
>
> 文件名为兼容仓库既有链接暂不修改；系统不提供“一键开票”或第三方服务商自动开票。

## 一、微信支付

支付逻辑在 `cicada-client-order`（下单、JSAPI 支付、回调、查单）和 `cicada-admin-order`（退款、人工对账）两个云函数。本项目使用 `uni.requestPayment`，没有使用 `uni-pay`。

```text
创建预支付单 -> uni.requestPayment -> 微信异步通知/服务端主动查单 -> 确认到账 -> 后续维修
```

必须遵守：

- 客户端支付成功回调不是到账凭证，不能直接写 `payment_status=paid`。
- 只有服务端验签回调或微信查单成功后才能确认到账。
- 微信支付订单的 `payment_method=wechat_pay`，不显示开票申请，也不能由后台登记发票。
- 商户私钥、APIv3 密钥和支付公钥只能放在云函数环境变量中。

### 微信支付环境变量

| 环境变量 | 说明 |
|---|---|
| `WX_PAY_APPID`（或 `WX_APPID`） | 小程序 AppID `wx25289fbe4a3bf011` |
| `WX_PAY_MCH_ID` | 微信支付商户号 |
| `WX_PAY_SERIAL_NO` | 商户 API 证书序列号 |
| `WX_PAY_PRIVATE_KEY`（或分段 Base64） | 商户 API 私钥 |
| `WX_PAY_API_V3_KEY` | APIv3 密钥 |
| `WX_PAY_PUBLIC_KEY_ID` | 微信支付公钥 ID |
| `WX_PAY_PUBLIC_KEY`（或分段 Base64） | 微信支付公钥 PEM |
| `WX_PAY_NOTIFY_URL` | `cicada-client-order/wechatPayNotify` URL 化地址 |

uniCloud 单个环境变量值最多 1024 字符。Base64 超限时按顺序拆为 `_1`、`_2`、`_3`，中间不能缺段。

## 二、对公收款账户

后台“系统设置 -> 联系与公众号 -> 对公转账账户”维护以下字段；工单收款页、结算管理页和客户转账弹窗读取同一配置：

| 字段 | 当前值 |
|---|---|
| 户名 | 佛山市登煌医疗器械有限公司 |
| 开户行 | 中国农业银行佛山惠景支行 |
| 账号 | 4442 3201 0400 04288 |

客户转账时必须备注工单编号。客户上传凭证后，订单写入：

- `payment_method=offline_transfer`
- `payment_status=uploaded`

财务同步核对银行流水后在后台点击“审核通过”，订单才变为 `payment_status=paid`。

## 三、人工开票流程

```text
客户选择对公转账并上传凭证
  -> 财务核对银行流水并确认到账
  -> 检修服务交付并完成结单
  -> 客户提交开票资料
  -> 财务在电子税务局人工开具
  -> 后台工单“发票”页登记状态、号码、日期，可选上传 PDF 到项目云存储归档
  -> 客户在小程序查看已开票结果
```

统一校验位于 `common/cicada-invoice-policy`：

- 付款方式必须为 `offline_transfer` 或兼容旧值 `bank_transfer`。
- 工单状态必须为 `completed`。
- 付款状态必须已确认。
- 开票金额必须大于零。
- 微信支付订单即使已付款也不能申请或登记发票。
- 税收分类固定为“修理修配劳务”，发票项目固定为“牙科设备检修服务费”。

后台只保留 `updateInvoiceStatus` 人工登记接口；不存在 `issueInvoice`、自动开票按钮或 `INVOICE_PROVIDER_*` 配置。

### 小程序展示方式

- 财务登记“已开具”时填写发票抬头、发票号码、开票日期和金额，小程序直接展示这些结构化信息。
- 用户可在“发票与开票 -> 已开票”查看并一键复制发票信息，不下载 PDF，也不依赖外部文件域名。
- 小程序内展示的是发票信息摘要，不替代税务机关生成的电子发票原件；客户需要原件时由财务通过邮箱或其他约定渠道发送。

## 四、上线验证

1. 运行共享策略测试：`node --test uniCloud-alipay/cloudfunctions/common/cicada-invoice-policy/index.test.js`。
2. 在 `docte-master/` 运行 `npm run check`。
3. 验证微信支付成功后订单进入维修流程，小程序和后台均无发票登记入口。
4. 验证对公转账上传凭证后进入“待核销”，未核销时不能申请开票。
5. 财务确认到账但工单未完成时，验证客户端和后台仍不能申请或登记发票。
6. 工单完成结单后，验证客户可提交资料、后台可人工登记发票结果。
7. 登记测试发票号码、日期和抬头，验证客户可在小程序查看并复制完整发票信息。
8. 验证户名、开户行、账号在系统设置、工单收款和结算管理中保持一致。
